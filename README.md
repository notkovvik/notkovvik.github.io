# Лендинг notkovvik

Готовый статический сайт для https://notkovvik.github.io/ — без названия проекта в адресе.

## Публикация

1. Войдите в GitHub под аккаунтом notkovvik.
2. Создайте публичный репозиторий с точным именем `notkovvik.github.io`. Если он уже существует, сначала сохраните его текущие файлы: новый index.html заменит главную страницу.
3. Распакуйте архив и загрузите `index.html` в корень репозитория (не внутрь папки). README.md можно загрузить по желанию.
4. Откройте Settings → Pages.
5. В Build and deployment выберите Source: Deploy from a branch.
6. Выберите ветку main и папку / (root), затем Save. Если ваша ветка называется иначе, выберите её.
7. Дождитесь успешной публикации: сайт откроется по https://notkovvik.github.io/.

Сам репозиторий необходим для GitHub Pages. «Без репозитория в адресе» возможно, «без репозитория вообще» на GitHub Pages — нет. Сайт и страница репозитория имеют разные адреса.

## Возможности

- Публичные репозитории аккаунта загружаются автоматически через GitHub API, с пагинацией.
- Поиск по названиям, описаниям, языкам и темам.
- Кнопка сайта: используется ссылка из поля Website/About репозитория; если она не задана, но включён GitHub Pages, используется стандартный адрес Pages. Для нестандартных адресов и собственного домена заполните Website.
- Кнопка репозитория открывает исходный проект на GitHub.
- «Скачать код» открывает ZIP текущей основной ветки.
- «Файлы релизов» проверяет последний опубликованный обычный релиз и показывает его вложения. Для старых релизов и предварительных версий есть переход к списку релизов.
- Адаптивный макет, системная светлая/тёмная тема.
- Не требует сборки, библиотек, паролей или токена.

## Ограничения

GitHub ограничивает число анонимных запросов API (обычно 60 в час на IP). При превышении лимита сайт покажет сообщение и ссылку на GitHub. Приватные проекты не отображаются. Ссылки на сайты не проверяются на доступность.

Для готовых программ, APK и других загрузок прикрепите файлы к GitHub Release нужного репозитория. Файлы только внутри репозитория скачиваются вместе с архивом исходников, а не как отдельные релизные вложения.

Макет проверен на тестовых данных; доступность ваших реальных сайтов и релизов не проверялась. Из этого чата сайт ещё не опубликован.
